# Изменения за 12.10.2026

Коммиты в `main`: `e822a6f`, `0e53d63` (предыдущий — `57efdf2` от 09.10).

## 1. Вход на portal-sot.kz

**Что было сломано**

- После открытия портала Firefox показывал запрос «portal-sot.kz хочет получить
  доступ к другим приложениям и службам на этом устройстве — Разрешить /
  Блокировать». Пока никто не нажал «Разрешить», страница не могла связаться с
  NCALayer, и окно подписи ЭЦП не появлялось.
- Общий модуль входа нажимал на вкладку «Вход по ЭЦП» вместо кнопки «Войти».
- Вход без браузера отправлял на портал только подпись. KPI, Orion и InvestWay
  без пароля портала получали `USER NOT FOUND FOR XIN: <БИН>`.

**Что сделано**

- `scripts/portal_sot_login.py`, `scripts/poiskvsk.py`,
  `scripts/sud_fio_zayavlenie.py` — Firefox запускается с настройками
  `network.lna.blocking = false` и `network.lna.enabled = false`, запрос
  «Разрешить» больше не появляется.
- `scripts/portal_sot_login.py` — клик идёт по кнопке «Войти»
  (`LOGIN_BTN_EXACT_XPATH`), старый поиск оставлен как запасной.
- `scripts/portal_sot_auth.py`, `scripts/portal_sot_login.py` — при ответе
  `USER NOT FOUND` вход без браузера повторяется с паролем портала
  (`portal_password` из `PORTAL_SOT_BY_COMPANY`).

**Проверено:** вход через Firefox для Orion и InvestWay проходит с первой
попытки без ручных нажатий.

**Не проверено / не решено**

- Повтор входа без браузера с паролем: портал отвечает 403 на вход без
  браузера с этого сервера, проверить не удалось.
- KPI: пароль портала в `config.py` неверный (`INVALID SIGN`), нужен актуальный.
- «Поиск адреса в СК» целиком после правки не запускался.

## Открытые вопросы

- **Автозапуск заявлений на ИЛ** (пн и чт, 03:00 и 05:00) стоит в боевом
  режиме: подписывает и отправляет все отобранные сделки. Ночной запуск 12.10
  упал на входе в портал; днём оба скрипта запущены вручную и завершились
  успешно.
- **Второй этап возврата ГП** (`reestr_gp_import.py`): данные для расчёта
  задолженности берутся из базы CRM в момент запуска, сразу после того как
  `LoansImport.xlsx` положен в автоимпорт Дельты. Если Дельта не успела его
  подгрузить, в расчёте «Госпошлина (расходы)» будет 0, а остаток — меньше на
  сумму госпошлины. Правка не делалась, ждёт примера неправильного расчёта.
- **Реестр на возврат ГП по Омеге** даёт одну должницу: 846 из 864 подходящих
  займов уже с оплаченной госпошлиной, ещё 16 отсекает условие `F220 = 0`.
